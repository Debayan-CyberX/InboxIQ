# The Conversation Loop

Frontend-only evolution of the existing React 18 / Vite application. Express, Better Auth, Supabase, OAuth routes and all API modules remain unchanged.

Audit: The previous neutral identity was coherent but relied on a small hero product mockup, repeated restrained text compositions and very small UI labels. It lacked a memorable physical centerpiece, contrast between chapters, and cinematic sequencing. The application needed clearer surface hierarchy and more legible compact type.

Concept: A conversation is a continuous pathway between message, context and opportunity. Three custom folded ribbon geometries intersect into a single metallic sculpture. Pointer and scroll alter its framing; a single traveling marker represents a message along the route. A CSS/SVG fallback preserves the composition for reduced motion, data saving and unavailable WebGL. Geometry is procedural with no asset downloads or external HDR resources.

Campaign: near-black studio, silver/off-white typography, muted sage. Oversized grotesk with italic editorial contrast. Full-height opening, pale manifesto, interactive/scroll-linked conversation transformation, masked product reveal, asymmetric feature narratives and a lifecycle. Sample content stays explicitly fictional and sends no emails.

Workspace: framed application canvas, compact neutral sidebar, inset search, structured page labels, refined tables/boards, readable type, calm briefing and onboarding. Shared primitives cover every existing route, authentication, diagnostic and fallback pages. Preserve keyboard shortcuts, mutations and explicit send confirmation.

Dependencies: React Three Fiber v8 for React 18, Three.js, GSAP. WebGL and scroll libraries are dynamically loaded after initial content. No framework migration, paid services, backend changes or credential disclosure.

## Validation
- Existing workflow browser suite: 33 captures across 1440, 1024 and 390 pixels, both workspace themes and populated/empty states. Lead mutations, draft review/save/explicit confirmation, CSV, preferences, keyboard search/navigation and assistant flows pass; no real email sent.
- Cinematic browser suite: actual WebGL rendering, scroll-away/return, keyboard tabs, forced GPU-context loss/static recovery, responsive hero, authentication/404/diagnostic pages at all three widths, and reduced-motion mode without Three.js/GSAP network downloads. No browser runtime errors.
- Mobile art framing adjusted following screenshot review so the sculpture does not obscure supporting copy. Static auth art is masked to preserve text contrast.
- Existing APIs and server files are unchanged.

## Liquid intelligence hero update
The hero now uses a single continuously deforming, dark chrome orb. GPU vertex displacement and recalculated surface normals produce flowing reflections; a smoothed pointer field locally pulls the surface and eases back on exit. Narrow procedural studio panels and a slowly changing reflection orientation create silver highlights. Five independent diagonal light shafts animate behind the orb with a moving soft light source. Reduced-motion/data-saving/static fallback, offscreen pause and the document-flow text spacing remain intact. No backend or API changes.
